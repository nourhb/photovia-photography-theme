== Description ==

Photovia is a gallery-first Full Site Editing theme crafted for photographers — weddings, portraits, editorial and commercial shoots. Pure-black canvas with a warm amber accent, full-bleed gallery hero, masonry portfolio grids, lightbox-ready galleries, services and collection pricing, photographer about section, client testimonials, stats band, FAQ, booking CTA and an Instagram-style strip — everything a photography studio needs to turn visitors into bookings.

A clean, modern Full Site Editing (block) theme built with theme.json. Includes multiple page templates, curated block patterns, and "Midnight" and "Gallery Light" style variations. Translation-ready and accessibility-conscious.
