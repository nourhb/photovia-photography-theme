# Photovia — Photographer Portfolio WordPress Theme

A gallery-first Full Site Editing (block) theme for photographers: weddings, portraits, editorial and commercial shoots.

## Design

- Pure black (`#0a0a0a`) canvas + warm amber (`#f59e0b`) accent
- Full-bleed gallery hero with booking CTA
- Masonry and grid portfolio layouts with hover captions
- Click-to-zoom lightbox (vanilla JS, no dependencies)
- Photographer about section, services & collection pricing
- Client testimonials, animated stats band, FAQ
- Booking CTA with pulsing button, Instagram-style strip
- Inter typeface (bundled, OFL licensed)
- "Midnight" dark and "Gallery Light" style variations included

## Templates

| Template | Purpose |
|---|---|
| `front-page.html` | Gallery hero, masonry portfolio, about, services, stats, testimonials, Instagram strip, booking CTA |
| `page-portfolio.html` | Title + portfolio grid + lightbox gallery + booking CTA |
| `page-about.html` | Title + photographer about + stats + testimonials + booking CTA |
| `page-services.html` | Title + services packages + FAQ + booking CTA |
| `page-pricing.html` | Title + pricing collections + FAQ + booking CTA |
| `page-contact.html` | Title + contact info + FAQ |
| `page.html` / `page-wide.html` | Standard and wide page layouts |
| `single.html`, `archive.html`, `search.html`, `index.html`, `404.html` | Blog and utility templates |
